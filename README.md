# demo-spring

Este proyecto contiene una API REST desarrollada con Spring Boot.

## Documentación y ejemplos

La carpeta `docs/` contiene archivos de documentación y ejemplos de uso de las APIs REST disponibles.

- Ejemplo: `docs/postman_collection.json` (colección Postman con ejemplos de uso de los endpoints)

## Cómo agregar ejemplos de Postman

1. Coloca tu archivo Postman (por ejemplo, `postman_collection.json`) en la carpeta `docs/`.
2. Puedes referenciar este archivo en la documentación para facilitar el uso de los endpoints.

## Estructura recomendada

```
demo-spring/
├── docs/
│   └── postman_collection.json
├── src/
│   └── main/
│       └── ...
├── README.md
└── ...
```

## Notas
- No subas archivos sensibles como `application.properties` al repositorio.
- Usa `.gitignore` para excluir archivos con claves o configuraciones privadas.
